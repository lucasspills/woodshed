# Woodshed

A daily, graded, gamified piano practice app, built for one player (for now).

**Open it:** https://lucasspills.github.io/woodshed/ in Chrome. To install it as an app, use the install icon at the right of Chrome's address bar.

How it's built, how to work on it, and what's next: [BUILD-NOTES.md](BUILD-NOTES.md).
